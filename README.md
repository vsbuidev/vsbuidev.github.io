# Personal Portfolio Website

A modern and responsive portfolio website built with React, TypeScript, and Tailwind CSS.

## Features

- 📱 Fully Responsive Design
- 🎨 Modern UI/UX
- 🚀 Fast Performance
- 📄 Dynamic Resume Section

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Node.js
- React Icons
- Git/GitHub

## Sections

- About Me
- Tech Stack
- Education
- Past Experience
- Certifications
- Projects
- Resume

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/vsbuidev/vsbuidev.github.io.git
```

2. Install dependencies:

```bash
cd vsbuidev.github.io/
npm install
```

3. Run the development server:

```bash
npm run dev
```
